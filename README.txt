LOWPRICE GAMING

Contenido:
- index.html: sitio web completo.
- backend.json: catálogo, precios, moneda, WhatsApp y configuración de newsletter.

Importante:
backend.json funciona como fuente de datos/configuración para un sitio estático. JSON por sí solo no procesa pagos, autentica usuarios ni guarda pedidos en un servidor.

Para editar un producto:
1. Abrí backend.json.
2. Cambiá title, platform, old, price o appid.
3. El index.html actual conserva el catálogo embebido; para leer backend.json desde el navegador se necesita abrir el proyecto con un servidor local o conectar una API.
